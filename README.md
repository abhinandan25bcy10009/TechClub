# Tech Club - VIT Bhopal

A responsive landing page created for the Web Development Task Round. The website presents a simple and modern Tech Club / Community Showcase with information about the club, technical domains, features and events.

## Live Demo

[View Live Website](https://abhinandan25bcy10009.github.io/TechClub/)

## Key Features

- Responsive navigation bar
- Mobile-friendly hamburger menu
- Smooth navigation between sections
- Hero section with call-to-action
- Feature cards
- Technical domains section
- Events section
- Responsive layout for desktop, tablet and mobile
- Hover and transition effects
- Footer with navigation and social links

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
